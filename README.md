# AutoSearch - Consulta de Veículos (React SPA)

Projeto desenvolvido para a disciplina de Programação Web Fullstack.

## Requisitos do Projeto
- Single Page Application (SPA) em React.js
- Consumo de API JSON pública via AJAX (`fetch`)
- Hooks: `useReducer`, `useMemo`, `useRef`
- Recurso: `createPortal` para modal
- Biblioteca externa: `lucide-react`

## Como rodar o projeto

```bash
npm install
npm run dev
```
